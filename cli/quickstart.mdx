---
title: "Quickstart"
description: "Install the CLI, sign in, confirm the account you are on, and send your first transfer."
---

Five commands from an empty terminal to money that moved. You need an active HEVN account and either
`pipx` (Python 3.11+) or Homebrew.

## Install

`pipx` installs the CLI from PyPI into its own isolated environment:

```bash
pipx install hevn-cli
hevn --help
```

On macOS and Linux, Homebrew works too. The tap is the formula source, so the first command both taps
and installs:

```bash
brew install hevn-inc/tap/hevn-cli
hevn --help
```

Upgrade with `pipx upgrade hevn-cli` or `brew upgrade hevn-cli`.

## Sign in

```bash
hevn login
```

The CLI opens HEVN in a browser, waits for a local callback, saves your app API key and prints the
config path. On a remote machine, `hevn login --no-open` prints the URL instead of opening it, and
`hevn login --api-key hvn_...` saves a key you already hold without any browser at all.

That one key authenticates everything from here on, transfers included.

## Confirm which account you are on

Do this before the first write. `whoami` introspects the key itself — the owning app, its scopes,
the balance it can see and the spend limit it is bounded by:

```bash
hevn whoami
hevn whoami --yaml
```

`account get` and `balance` answer for the account rather than the key:

```bash
hevn account get
hevn balance
```

Every read takes `--json` or `--yaml`, which is what a script should use:

```bash
hevn account list --yaml
```

## Send something

Save a destination, then pay it:

```bash
hevn contacts new --type email --name "Vendor" --email vendor@example.com
hevn contacts list --yaml
hevn transfer contact --contact-id <contact-id> --amount 25 --memo "Thanks"
```

Paying an invoice needs only its id:

```bash
hevn transfer --invoice-id <invoice-id> --memo "Invoice payment"
```

Preview any mutating command before it sends by putting `--dry-run` before the resource:

```bash
hevn --dry-run transfer --invoice-id <invoice-id> --memo "Invoice payment"
```

## Sign out

```bash
hevn logout
```

<Warning>
  `hevn logout` clears the saved CLI credential fields from the local config file. It does not delete
  your HEVN account and does not revoke the key on the server — revoke that in the app.
</Warning>
