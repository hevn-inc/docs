| Environment | API base URL | App | Chain |
| --- | --- | --- | --- |
| Sandbox | `https://sandbox-api.hevn.finance/dapi/v1` | `https://sandbox.gethevn.com` | Base Sepolia |
| Production | `https://api.hevn.finance/dapi/v1` | `https://app.gethevn.com` | Base |

Developer keys, clients and tokens are per environment.

The examples read these variables:

```bash
export HEVN_API="https://sandbox-api.hevn.finance/dapi/v1"
export HEVN_EMAIL="integrator@example.com"
export HEVN_KEY_PEM="$HOME/.hevn/developer-key.pem"  # mode 0600, keep it out of your repo
export HEVN_CLIENT_ID="cl_7YQ2Kf3mN8"                # the client a call acts for
```

| Derived variable | Value |
| --- | --- |
| `HEVN_ACCESS_TOKEN` | The `accessToken` returned by [login](/developers/authentication#sessions). |
| `HEVN_USER_ID` | Your `cl_…` id, the `userId` returned by login. |
| `HEVN_PUBLIC_KEY` | The base64 public key of the PEM, sent as `publicKey` to `POST /dapi/v1/payouts`. |

```bash
export HEVN_PUBLIC_KEY=$(openssl ec -in "$HEVN_KEY_PEM" -pubout -outform DER 2>/dev/null \
  | base64 | tr -d '\n')
```
