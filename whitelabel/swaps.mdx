---
title: "Swaps"
description: "Move money between two accounts of your integrator account, for example USDC to EURC."
---

A swap moves money between two accounts that the same owner holds, for example `USDC` to `EURC`. Create one with `POST /dapi/v1/swaps` and sign it with your developer key.

The [sign-in window](/whitelabel/sign-in-with-hevn) does not approve swaps, so a session acting for a client can preview a swap but cannot create one.

`sourceAccount` and `destinationAccount` take the account names in [Accounts](/whitelabel/overview#accounts).

## Preview a swap

`POST /dapi/v1/swaps/preview` returns the best price among the routes that serve the pair. Preview has no side effects.

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/swaps/preview" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sourceAccount":"USDC","destinationAccount":"EURC","amount":"500.00"}'
```

```python Python
priced = hevn.post("/swaps/preview", {
    "sourceAccount": "USDC",
    "destinationAccount": "EURC",
    "amount": "500.00",
})
```

```javascript Node
const priced = await hevn.post("/swaps/preview", {
  sourceAccount: "USDC",
  destinationAccount: "EURC",
  amount: "500.00",
});
```

```go Go
priced, err := api.Post("/swaps/preview", hevn.Body{
	"sourceAccount":      "USDC",
	"destinationAccount": "EURC",
	"amount":             "500.00",
})
```
</CodeGroup>

```json Response: 200
{ "sourceAccount": "USDC",
  "destinationAccount": "EURC",
  "quote": { "fromAmount": "500.00", "fromCurrency": "USDC",
             "toAmount": "462.14", "toCurrency": "EURC",
             "rate": "0.924280", "feeAmount": "0.75", "feeCurrency": "USDC",
             "minimumToAmount": "461.21", "estimated": false,
             "expiresAt": "2026-09-20T18:12:41Z" } }
```

Fields: [Price a transfer between the client's own accounts](/api-reference/transfers/price-a-transfer-between-the-clients-own-accounts).

## Create and confirm

Call `POST /dapi/v1/swaps` with the preview body plus `publicKey` and an [`Idempotency-Key`](/whitelabel/conventions#idempotency-key). It prices the swap again and returns the approval.

```json Response: 201, Location: /dapi/v1/swaps/swp_9f2c1ab84d
{ "id": "swp_9f2c1ab84d",
  "status": "awaitingSignature",
  "idempotencyKey": "swap-A-1187",
  "sourceAccount": "USDC",
  "destinationAccount": "EURC",
  "quote": { "fromAmount": "500.00", "fromCurrency": "USDC",
             "toAmount": "462.14", "toCurrency": "EURC",
             "rate": "0.924280", "feeAmount": "0.75", "feeCurrency": "USDC" },
  "authorization": "debit",
  "approval": { "id": "b1e7…", "payload": "eyJib2R5Ijp7…", "expiresAt": "2026-09-20T18:10:59Z" },
  "debit": { "address": "0x8c41…", "amount": "500.00", "amountAtomic": "500000000",
             "token": "USDC", "chainId": 8453 } }
```

When `authorization` is `debit`, compare `debit.address`, `debit.amount` and `debit.token` with the swap you meant before you sign. Fields: [Create a transfer between the client's own accounts](/api-reference/transfers/create-a-transfer-between-the-clients-own-accounts).

Sign `approval.payload` and post it to `POST /dapi/v1/swaps/{swapId}/confirm` ([Signing](/whitelabel/signing)).

Confirm returns `202` with a `pollUrl`. Read `GET /dapi/v1/swaps/{swapId}` until `status` is `settled` or `failed`. While the approval is open, retry as described in [Retrying a confirm](/whitelabel/signing#retrying-a-confirm). Once the approval is used or expired, confirm returns `409 swap_not_confirmable`, so read the swap.

## Read a swap

`GET /dapi/v1/swaps/{swapId}` returns the status and the quote the swap was fixed at.

```json Response: 200
{ "id": "swp_9f2c1ab84d",
  "status": "settled",
  "sourceAccount": "USDC",
  "destinationAccount": "EURC",
  "quote": { "fromAmount": "500.00", "fromCurrency": "USDC",
             "toAmount": "462.14", "toCurrency": "EURC",
             "rate": "0.924280", "feeAmount": "0.75", "feeCurrency": "USDC" },
  "transactionHash": "0x7d2b…",
  "transactionId": "txn_5c9e2f…",
  "createdAt": "2026-09-20T18:08:44Z",
  "settledAt": "2026-09-20T18:09:12Z" }
```

A swap that involves an `FDIC_*` account has a `transactionId` once it is on the [ledger](/whitelabel/balances-and-transactions). Between token accounts `transactionId` is null, so match the swap on `transactionHash`. Fields: [Retrieve a transfer between the client's own accounts](/api-reference/transfers/retrieve-a-transfer-between-the-clients-own-accounts).

To pay out of `FDIC_USD` without a swap, see [Payouts](/whitelabel/payouts#bank-held-balance).

## Statuses

| `status` | Meaning | Next |
| --- | --- | --- |
| `awaitingSignature` | Created and not yet confirmed. | Sign and confirm. |
| `submitted` | Confirmed and settling. | Read the swap. |
| `settled` | Settlement completed. | n/a |
| `failed` | The swap did not settle. | Read `failure.code`. |

## Refusals

| Error | Cause | Action |
| --- | --- | --- |
| `400 invalid_request` | No route serves the pair. | Choose another pair of accounts. |
| `422 account_unavailable` | The owner does not hold the `FDIC_*` account. | Use an account from the [balance](/whitelabel/balances-and-transactions#balance). |
| `422 swap_route_unavailable` | The [sandbox](/whitelabel/sandbox) does not run swaps or previews. | n/a |
| `403 account_not_controlled` | `POST /dapi/v1/swaps` was called with a client in `X-Hevn-Account`. | Swap only your own accounts. A client's accounts cannot be swapped through the API. |
| `409 swap_not_confirmable` | The approval was used or has expired. | Read the swap. |

Other codes: [Errors](/whitelabel/reference/errors).
