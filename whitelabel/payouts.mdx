---
title: "Payouts"
description: "Save a contact, book a payout to a bank account or a wallet, and track it to settlement."
---

A payout sends money from an account to a saved contact, which is a bank account or a wallet address. Save the contact with `POST /dapi/v1/contacts`, then book the payout with `POST /dapi/v1/payouts`.

The holder approves a client's payout. Your developer key signs a payout from your account ([Who can spend](/whitelabel/overview#who-can-spend)). These routes are client-scoped and take `X-Hevn-Account` ([Acting as a client](/whitelabel/authentication#acting-as-a-client)).

## Save a contact

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/contacts" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ardenne Fabrication SARL",
       "bank":{"method":"sepa","currency":"EUR",
               "fields":{"iban":"DE89370400440532013000"},
               "holder":{"type":"business","businessName":"Ardenne Fabrication SARL"},
               "bankName":"Example Bank"},
       "address":{"country":"FR","city":"Lyon","streetAddress":"12 Rue Garibaldi","zip":"69006"}}'
```

```python Python
contact = client.post("/contacts", {
    "name": "Ardenne Fabrication SARL",
    "bank": {
        "method": "sepa",
        "currency": "EUR",
        "fields": {"iban": "DE89370400440532013000"},
        "holder": {"type": "business", "businessName": "Ardenne Fabrication SARL"},
        "bankName": "Example Bank",
    },
    "address": {"country": "FR", "city": "Lyon", "streetAddress": "12 Rue Garibaldi", "zip": "69006"},
})
```

```javascript Node
const contact = await client.post("/contacts", {
  name: "Ardenne Fabrication SARL",
  bank: {
    method: "sepa",
    currency: "EUR",
    fields: { iban: "DE89370400440532013000" },
    holder: { type: "business", businessName: "Ardenne Fabrication SARL" },
    bankName: "Example Bank",
  },
  address: { country: "FR", city: "Lyon", streetAddress: "12 Rue Garibaldi", zip: "69006" },
});
```

```go Go
contact, err := client.Post("/contacts", hevn.Body{
	"name": "Ardenne Fabrication SARL",
	"bank": hevn.Body{
		"method":   "sepa",
		"currency": "EUR",
		"fields":   hevn.Body{"iban": "DE89370400440532013000"},
		"holder":   hevn.Body{"type": "business", "businessName": "Ardenne Fabrication SARL"},
		"bankName": "Example Bank",
	},
	"address": hevn.Body{"country": "FR", "city": "Lyon", "streetAddress": "12 Rue Garibaldi", "zip": "69006"},
})
```
</CodeGroup>

```json Response 201, Location: /dapi/v1/contacts/ct_3K9…
{ "id": "ct_3K9…", "name": "Ardenne Fabrication SARL", "isExternal": true,
  "bank": { "method": "sepa", "state": "active", … }, … }
```

The identifiers each method needs in `bank.fields` are in [Rails](/whitelabel/reference/rails#what-each-method-needs). Field rules are on [Create a contact](/api-reference/contacts/create-a-contact). To edit, delete or list contacts, see [Update a contact](/api-reference/contacts/update-a-contact), [Delete a contact](/api-reference/contacts/delete-a-contact) and [List saved contacts](/api-reference/contacts/list-saved-contacts).

### Check capabilities

Both calls are optional. `POST /dapi/v1/payouts` applies the same checks.

- [Retrieve contact channels](/api-reference/contacts/retrieve-contact-channels) lists the options that can pay the contact, with limits, fees, the payout fields each one requires and blockers ([Contact blockers](/whitelabel/reference/errors#contact-blockers), [Fees](/whitelabel/reference/rails#fees)).
- [Create an outgoing transfer quote](/api-reference/transfers/create-an-outgoing-transfer-quote) prices a payment method and amount without a contact.

## Book the payout

Call `POST /dapi/v1/payouts` with the contact and one amount.

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/payouts" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
  -H "Idempotency-Key: order-A-1187" \
  -H "Content-Type: application/json" \
  -d '{"contactId":"ct_3K9…","amount":"500.00","paymentReference":"INV-2026-114"}'
```

```python Python
payout = client.post("/payouts", {
    "contactId": contact["id"],
    "amount": "500.00",
    "paymentReference": "INV-2026-114",
}, idempotency_key="order-A-1187")
```

```javascript Node
const payout = await client.post("/payouts", {
  contactId: contact.id,
  amount: "500.00",
  paymentReference: "INV-2026-114",
}, { idempotencyKey: "order-A-1187" });
```

```go Go
payout, err := client.Post("/payouts", hevn.Body{
	"contactId":        contact.Str("id"),
	"amount":           "500.00",
	"paymentReference": "INV-2026-114",
}, hevn.IdempotencyKey("order-A-1187"))
```
</CodeGroup>

```json Response 201, Location: /dapi/v1/payouts/po_4c8a…
{
  "id": "po_4c8a…",
  "kind": "fiat",
  "status": "awaitingSignature",
  "idempotencyKey": "order-A-1187",
  "quote": { "fromAmount": "500.00", "fromCurrency": "USD", "sourceAccount": "USDC",
             "toAmount": "459.31", "toCurrency": "EUR",
             "rate": "0.9247", "feeAmount": "1.00", "feeCurrency": "USD",
             "expiresAt": "2026-09-17T10:06:11Z" },
  "authorization": "client",
  "contact": { "contactId": "ct_3K9…", "name": "Ardenne Fabrication SARL" }
}
```

The body fields and the response are on [Create an outgoing transfer](/api-reference/transfers/create-an-outgoing-transfer). To pay from the fiat balance, see [Bank-held balance](#bank-held-balance).

With `authorization: "client"`, show the holder `quote` and `contact`, then open the sign-in window.

### Retries

Send an `Idempotency-Key` with each booking. Key format, replay windows and bookings without a key are in [Idempotency-Key](/whitelabel/conventions#idempotency-key).

A retry with the same key and terms returns the same `po_…` and quote. Until the payout is funded, a replay on your account returns a new `approval`, and a replay for a client returns `authorization: "client"` again, so create a new `sign` session. The rules for a changed request are on [Create an outgoing transfer](/api-reference/transfers/create-an-outgoing-transfer).

A retry under the same key with another `sourceAccount` returns `409 idempotency_key_reused`. Without a key, a request with another `sourceAccount` books a new payout.

<Warning>
  Reuse the key when you retry. A new key books a second payout.
</Warning>

## Approve it in the sign-in window

Create a session with `POST /dapi/v1/connect/sessions`, passing `action: "sign"` and the `payoutId`, without `X-Hevn-Account`. Then open the window. Session rules and the callback are in [Approve a payout](/whitelabel/sign-in-with-hevn#approve-a-payout).

| Case | Behaviour |
| --- | --- |
| Quote expired | A routed payout's quote expires at `quote.expiresAt`, and the window then returns `unsupported`. Open it right after booking. |
| Declined or closed | The payout stays `awaitingSignature`. Create a new `sign` session for the same `po_…`. |

## Track it to completion

Read `GET /dapi/v1/payouts/{payoutId}`. A `pollUrl` points to this route ([polling](/whitelabel/conventions#status-codes)).

```json Response 200
{ "id": "po_4c8a…", "kind": "fiat", "status": "settled",
  "quote": { … }, "contact": { … },
  "transactionHash": "0x4f1c…", "transactionId": "txn_9e4…",
  "createdAt": "2026-09-17T10:04:11Z", "settledAt": "2026-09-17T10:04:39Z" }
```

| `status` | Meaning | Next |
| --- | --- | --- |
| `awaitingSignature` | Booked and quoted. It is not signed and no money has moved. | Get the signature. |
| `submitted` | The funding operation was sent, or the partner bank holds the payout (`attention`). | Poll. |
| `settled` | The debit landed and the partner bank accepted the payout. Delivery timing is set by the partner bank. | Read the ledger row. |
| `failed` | The payout did not complete. `failure.code` names the cause, listed on [Retrieve an outgoing transfer](/api-reference/transfers/retrieve-an-outgoing-transfer). | Book again with the same `Idempotency-Key`. After `409 payment_slot_consumed`, use a new key ([Retrying a confirm](/whitelabel/signing#retrying-a-confirm)). |
| `refunded` | The partner bank returned the money to the wallet. | Reconcile. |

The fields of the read, `attention` and `transactionId` among them, are on [Retrieve an outgoing transfer](/api-reference/transfers/retrieve-an-outgoing-transfer).

## Pay from your own account

Book without `X-Hevn-Account`, or with your `cl_…` in it, and add `publicKey`.

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/payouts" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "Idempotency-Key: treasury-2026-09-17" \
  -H "Content-Type: application/json" \
  -d '{"contactId":"ct_3K9…","amount":"500.00",
       "publicKey":"'"$HEVN_PUBLIC_KEY"'","paymentReference":"INV-2026-114"}'
```

```python Python
payout = hevn.post("/payouts", {
    "contactId": contact["id"],
    "amount": "500.00",
    "publicKey": key.public_key,
    "paymentReference": "INV-2026-114",
}, idempotency_key="treasury-2026-09-17")
```

```javascript Node
const payout = await hevn.post("/payouts", {
  contactId: contact.id,
  amount: "500.00",
  publicKey: key.publicKey,
  paymentReference: "INV-2026-114",
}, { idempotencyKey: "treasury-2026-09-17" });
```

```go Go
payout, err := api.Post("/payouts", hevn.Body{
	"contactId":        contact.Str("id"),
	"amount":           "500.00",
	"publicKey":        key.PublicKey,
	"paymentReference": "INV-2026-114",
}, hevn.IdempotencyKey("treasury-2026-09-17"))
```
</CodeGroup>

```json Response 201, Location: /dapi/v1/payouts/po_7e1b…
{
  "id": "po_7e1b…",
  "kind": "fiat",
  "status": "awaitingSignature",
  "quote": { … },
  "authorization": "debit",
  "approval": { "id": "…", "payload": "eyJ…", "expiresAt": "2026-09-17T10:06:10Z" },
  "debit": { "address": "0x8f3b…", "amount": "500.00", "amountAtomic": "500000000",
             "token": "USDC", "chainId": 8453 }
}
```

Check `debit`, sign `approval.payload` and post the signature to `POST /dapi/v1/payouts/{payoutId}/confirm` ([Signing](/whitelabel/signing), [Authorize an outgoing transfer](/api-reference/transfers/authorize-an-outgoing-transfer)). Confirm outcomes are in [Retrying a confirm](/whitelabel/signing#retrying-a-confirm).

## Pay a wallet

A wallet contact uses the same payout body, `sign` session and read. The payout has `kind: "onchain"`.

### Save an address as a contact

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/contacts" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ardenne treasury","crypto":{"chain":"base","token":"USDC","address":"0x7c1d…"}}'
```

```python Python
contact = client.post("/contacts", {
    "name": "Ardenne treasury",
    "crypto": {"chain": "base", "token": "USDC", "address": "0x7c1d…"},
})
```

```javascript Node
const contact = await client.post("/contacts", {
  name: "Ardenne treasury",
  crypto: { chain: "base", token: "USDC", address: "0x7c1d…" },
});
```

```go Go
contact, err := client.Post("/contacts", hevn.Body{
	"name":   "Ardenne treasury",
	"crypto": hevn.Body{"chain": "base", "token": "USDC", "address": "0x7c1d…"},
})
```
</CodeGroup>

`chain` takes a [chain code](/whitelabel/reference/rails#chain-codes).

| Contact | Payout | `quote` | `debit.address` on your account |
| --- | --- | --- | --- |
| USDC or EURC on Base | Direct, no conversion | `fromAmount` equals `toAmount`. `fromChainId` and `toChainId` are `base`. `expiresAt` is 15 minutes after booking. No `rate` or `feeAmount`. | `contact.address` |
| Another chain or token | Routed across chains | `fromChainId`, `toChainId`, `feeAmount` in `USD`, `expiresAt`. No `rate`. | A one-time address for the route |

On a direct payout and on a payout to a HEVN account, `amountTo` equals `amount`. An amount with more decimals than the token returns `422 validation_failed`.

### A routed payout is priced

```json Routed payout, response 201
{ "id": "po_6d21…", "kind": "onchain", …,
  "quote": { "fromAmount": "1.50", "toAmount": "1.4923", …,
             "feeAmount": "0.0077", "feeCurrency": "USD",
             "expiresAt": "2026-09-17T10:06:11Z",
             "fromChainId": "base", "toChainId": "arb" },
  "contact": { "contactId": "ct_9a…", "name": "Ardenne treasury",
               "address": "0x7c1d…", "chainId": "arb", "token": "USDC" } }
```

| Wallet payout refusal | Cause |
| --- | --- |
| `409 payout_not_fundable` | The account has no routing. Use a USDC or EURC contact on Base. |
| `400` | The address is the paying account's wallet. |
| `409 insufficient_funds` | The balance does not cover the amount. Fund the wallet. On your account, confirm again. |

The ledger row of a settled wallet payout has `isIncome: false` and `type: "crypto"`, or `internal` when the address belongs to another HEVN account ([Walk the ledger](/whitelabel/balances-and-transactions#walk-the-ledger)).

## Bank-held balance

Send `"sourceAccount": "FDIC_USD"` to pay from the balance the partner bank holds for the account. The wallet is not debited, and you sign the payout terms.

<CodeGroup>
```bash cURL
curl -s -X POST "$HEVN_API/payouts" \
  -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
  -H "Idempotency-Key: payout-A-1188" \
  -H "Content-Type: application/json" \
  -d '{"contactId":"ct_3K9…","amount":"500.00","sourceAccount":"FDIC_USD","publicKey":"'$HEVN_PUBLIC_KEY'"}'
```

```python Python
payout = hevn.post("/payouts", {
    "contactId": "ct_3K9…",
    "amount": "500.00",
    "sourceAccount": "FDIC_USD",
    "publicKey": key.public_key,
}, idempotency_key="payout-A-1188")
```

```javascript Node
const payout = await hevn.post("/payouts", {
  contactId: "ct_3K9…",
  amount: "500.00",
  sourceAccount: "FDIC_USD",
  publicKey: key.publicKey,
}, { idempotencyKey: "payout-A-1188" });
```

```go Go
payout, err := api.Post("/payouts", hevn.Body{
	"contactId":     "ct_3K9…",
	"amount":        "500.00",
	"sourceAccount": "FDIC_USD",
	"publicKey":     key.PublicKey,
}, hevn.IdempotencyKey("payout-A-1188"))
```
</CodeGroup>

```json Response 201
{ "id": "po_4c8a13d7f2", …,
  "authorization": "intent",
  "quote": { "fromCurrency": "USD", "sourceAccount": "FDIC_USD", … },
  "approval": { … },
  "intent": { "digest": "0x9c1f…", "settles": "message_signature" } }
```

Check `quote` and `intent`, then sign, confirm and poll as for any payout from your account. A client cannot pay from `FDIC_USD`. The refusals are under `sourceAccount` on [Create an outgoing transfer](/api-reference/transfers/create-an-outgoing-transfer).

To move the balance to your wallet, use [Swaps](/whitelabel/swaps).

## When a payout is refused

`POST /dapi/v1/payouts` returns these codes. A `400` or `422` comes before booking, so the same key works for the corrected request.

| `code` | Status | Cause and fix |
| --- | --- | --- |
| `invalid_request` | 400 | The terms are not accepted, for example an amount below the minimum, a direction that cannot be priced, or account details the method does not accept. The reason is in `message`. |
| `payout_not_fundable` | 409 | With `details.reason = "holder_signature_unsupported"`, pay from `USDC` or `EURC`. Otherwise book again with a new key on a rail that can be funded. |
| `provider_unavailable` | 503 | The partner bank is unavailable. Retry with the same key. |

The other codes, among them `404 contact_not_found`, `409 contact_not_payable` and `422 contact_payment_details_invalid`, are in [Errors](/whitelabel/reference/errors#payouts). To move a booked payout in the sandbox, see [Move a payout](/whitelabel/sandbox#move-a-payout).
