Link one client, fund its wallet and settle one holder-approved payout in the sandbox. Start by logging in with `POST /dapi/v1/auth/challenge` and `POST /dapi/v1/auth/token`.

## Before you start

1. Sign up at [`https://sandbox.gethevn.com`](https://sandbox.gethevn.com).
2. Open **Settings → Partner program → Developer** and create a developer key. Set its [IP allowlist](/whitelabel/authentication#the-ip-allowlist) to your machine's egress address.
3. Save the private key to `$HEVN_KEY_PEM` with mode `0600`.
4. In the Sign-in window card, add `http://localhost:8080` under **Allowed sites** and save.
5. Have a second Google account with no HEVN sandbox account. Linking an existing account fails with `already_registered`.
6. Set the environment and install the dependencies.

## Steps

<Steps>
  <Step title="Log in">
    Run the login code in [Sessions](/whitelabel/authentication#sessions). Export `accessToken` as `HEVN_ACCESS_TOKEN` and `userId` as `HEVN_USER_ID`. The Python, Node and Go tabs use the [reference client](/whitelabel/reference/client).
  </Step>

  <Step title="Serve the two pages">
    Save both files in an empty folder and serve it on the allowed origin.

    ```html index.html
    <!doctype html>
    <meta charset="utf-8">
    <title>HEVN quickstart</title>
    <input id="url" placeholder="Paste a session url" size="90">
    <button id="open">Open HEVN</button>
    <pre id="out"></pre>
    <script>
      const out = document.getElementById("out");
      const channel = new BroadcastChannel("hevn-connect");
      channel.onmessage = ({ data }) => { out.textContent = JSON.stringify(data.result, null, 2); };
      document.getElementById("open").onclick = () => {
        window.open(document.getElementById("url").value, "hevn-connect", "popup,width=460,height=720");
      };
    </script>
    ```

    ```html callback.html
    <!doctype html>
    <meta charset="utf-8">
    <title>Signing in…</title>
    <script>
      const result = Object.fromEntries(new URLSearchParams(location.search));
      if (result.state) {
        const channel = new BroadcastChannel("hevn-connect");
        channel.postMessage({ state: result.state, result });
        channel.close();
        window.close();
      }
    </script>
    ```

    ```bash
    python3 -m http.server 8080
    ```

    Open `http://localhost:8080`. A production page needs the checks in [Sign in with HEVN](/whitelabel/sign-in-with-hevn).
  </Step>

  <Step title="Create a link session">
    Call `POST /dapi/v1/connect/sessions` with `action: "link"`. Do not send `X-Hevn-Account`.

    <CodeGroup>

    ```bash cURL
    curl -s -X POST "$HEVN_API/connect/sessions" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "Content-Type: application/json" \
      -d '{"action":"link","redirectUri":"http://localhost:8080/callback.html"}' | jq -r .url
    ```

    ```python Python
    session = hevn.post("/connect/sessions", {
        "action": "link", "redirectUri": "http://localhost:8080/callback.html",
    })
    print(session["url"])
    ```

    ```javascript Node
    const session = await hevn.post("/connect/sessions", {
      action: "link", redirectUri: "http://localhost:8080/callback.html",
    });
    console.log(session.url);
    ```

    ```go Go
    session, err := api.Post("/connect/sessions", hevn.Body{
    	"action": "link", "redirectUri": "http://localhost:8080/callback.html",
    })
    fmt.Println(session.Str("url"))
    ```

    </CodeGroup>

    ```json Response
    { "url": "https://sandbox.gethevn.com/connect?session=eyJ…", … }
    ```

    | Error | Cause |
    | --- | --- |
    | `403 redirect_uri_not_allowed` | `http://localhost:8080` is not an allowed site. |
    | `403 client_creation_not_enabled` | Your account is [not an active integrator](/whitelabel/sandbox#what-hevn-must-enable). |
  </Step>

  <Step title="Sign in as the customer">
    Paste the URL into the page within 10 minutes, click **Open HEVN** and sign in with the second Google account. The page shows the result.

    ```json
    { "code": "eyJhbGciOiJFUzI1NiIs…", "state": "pQ8v2Zr0…" }
    ```
  </Step>

  <Step title="Exchange the code">
    Call `POST /dapi/v1/clients/link` with the code within 5 minutes.

    <CodeGroup>

    ```bash cURL
    curl -s -X POST "$HEVN_API/clients/link" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "Content-Type: application/json" \
      -d '{"code":"eyJhbGciOiJFUzI1NiIs…"}' | jq '{id, status, baseSmartWallet}'
    ```

    ```python Python
    linked = hevn.post("/clients/link", {"code": code})
    client = hevn.acting_as(linked["id"])
    ready = poll_until(lambda: client.get("/client"),
                       lambda seen: seen["status"] != "provisioning")
    ```

    ```javascript Node
    const linked = await hevn.post("/clients/link", { code });
    const client = hevn.actingAs(linked.id);
    const ready = await pollUntil(() => client.get("/client"),
      (seen) => seen.status !== "provisioning");
    ```

    ```go Go
    linked, err := api.Post("/clients/link", hevn.Body{"code": code})
    client := api.ActingAs(linked.Str("id"))
    ready, err := hevn.PollUntil(
    	func() (hevn.Payload, error) { return client.Get("/client") },
    	func(seen hevn.Payload) bool { return seen.Str("status") != "provisioning" },
    	2*time.Minute,
    )
    ```

    </CodeGroup>

    ```json Response
    { "id": "cl_7YQ2Kf3mN8", "status": "ready", "baseSmartWallet": "0x2f1c9d0b8a7e6532d41ac9f0b3e27d5581a4c6f9" }
    ```

    Export the id as `HEVN_CLIENT_ID`. While `status` is `provisioning`, poll `GET /dapi/v1/client` with the id in `X-Hevn-Account` every two seconds.
  </Step>

  <Step title="Fund the wallet">
    Call [`POST /dapi/v1/sandbox/deposits`](/whitelabel/sandbox#mint-money) with the client id in `X-Hevn-Account`.

    <CodeGroup>

    ```bash cURL
    curl -X POST "$HEVN_API/sandbox/deposits" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
      -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
      -H "Idempotency-Key: quickstart-deposit-1" \
      -H "Content-Type: application/json" -d '{"amount":"5.00","token":"USDC"}'
    ```

    ```python Python
    credit = client.post("/sandbox/deposits", {"amount": "5.00", "token": "USDC"},
                            idempotency_key="quickstart-deposit-1")
    ```

    ```javascript Node
    const credit = await client.post("/sandbox/deposits",
      { amount: "5.00", token: "USDC" },
      { idempotencyKey: "quickstart-deposit-1" });
    ```

    ```go Go
    credit, err := client.Post("/sandbox/deposits", hevn.Body{"amount": "5.00", "token": "USDC"},
    	hevn.IdempotencyKey("quickstart-deposit-1"))
    ```

    </CodeGroup>

    `200` means the tokens are in the wallet. On `202`, repeat the request with the same `Idempotency-Key`.
  </Step>

  <Step title="Read the balance">
    Call `GET /dapi/v1/client/balance`. Without `X-Hevn-Account` the route returns `422`.

    <CodeGroup>

    ```bash cURL
    curl -s "$HEVN_API/client/balance" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
      -H "X-Hevn-Account: $HEVN_CLIENT_ID" | jq
    ```

    ```python Python
    balance = client.get("/client/balance")
    ```

    ```javascript Node
    const balance = await client.get("/client/balance");
    ```

    ```go Go
    balance, err := client.Get("/client/balance")
    ```

    </CodeGroup>

    ```json Response
    { "baseSmartWallet": "0x2f1c…", "accounts": [{ "account": "USDC", "balance": "5.000000" }], … }
    ```
  </Step>

  <Step title="Book a payout">
    Read your wallet address from `GET /dapi/v1/client/balance` with `userId` from step 1 in `X-Hevn-Account`. Save it with `POST /dapi/v1/contacts`, then book `1.00` to it with `POST /dapi/v1/payouts`.

    <CodeGroup>

    ```bash cURL
    export HEVN_OWN_WALLET=$(curl -s "$HEVN_API/client/balance" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" \
      -H "X-Hevn-Account: $HEVN_USER_ID" | jq -r .baseSmartWallet)

    export HEVN_CONTACT_ID=$(curl -s -X POST "$HEVN_API/contacts" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
      -H "Content-Type: application/json" \
      -d "{\"name\":\"Treasury\",\"crypto\":{\"chain\":\"base\",\"token\":\"USDC\",\"address\":\"$HEVN_OWN_WALLET\"}}" | jq -r .id)

    curl -s -X POST "$HEVN_API/payouts" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
      -H "Idempotency-Key: quickstart-payout-1" -H "Content-Type: application/json" \
      -d "{\"contactId\":\"$HEVN_CONTACT_ID\",\"amount\":\"1.00\"}"
    ```

    ```python Python
    own_wallet = hevn.acting_as(user_id).get("/client/balance")["baseSmartWallet"]
    contact = client.post("/contacts", {
        "name": "Treasury",
        "crypto": {"chain": "base", "token": "USDC", "address": own_wallet},
    })
    payout = client.post("/payouts", {"contactId": contact["id"], "amount": "1.00"},
                            idempotency_key="quickstart-payout-1")
    ```

    ```javascript Node
    const { baseSmartWallet: ownWallet } = await hevn.actingAs(userId).get("/client/balance");
    const contact = await client.post("/contacts", {
      name: "Treasury",
      crypto: { chain: "base", token: "USDC", address: ownWallet },
    });
    const payout = await client.post("/payouts", { contactId: contact.id, amount: "1.00" },
      { idempotencyKey: "quickstart-payout-1" });
    ```

    ```go Go
    own, err := api.ActingAs(userID).Get("/client/balance")
    contact, err := client.Post("/contacts", hevn.Body{
    	"name":   "Treasury",
    	"crypto": hevn.Body{"chain": "base", "token": "USDC", "address": own.Str("baseSmartWallet")},
    })
    payout, err := client.Post("/payouts", hevn.Body{"contactId": contact.Str("id"), "amount": "1.00"},
    	hevn.IdempotencyKey("quickstart-payout-1"))
    ```

    </CodeGroup>

    ```json Response
    { "id": "po_6d21…", "status": "awaitingSignature", "authorization": "client", … }
    ```

    `authorization: "client"` means the holder approves this payout. Export the id as `HEVN_PAYOUT_ID`.

    A new [`Idempotency-Key`](/whitelabel/conventions#idempotency-key) books a second payout.
  </Step>

  <Step title="Approve the payout">
    Call `POST /dapi/v1/connect/sessions` with `action: "sign"` and the payout id, then open the URL from the page as in step 4.

    <CodeGroup>

    ```bash cURL
    curl -s -X POST "$HEVN_API/connect/sessions" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "Content-Type: application/json" \
      -d "{\"action\":\"sign\",\"payoutId\":\"$HEVN_PAYOUT_ID\",\"redirectUri\":\"http://localhost:8080/callback.html\"}" \
      | jq -r .url
    ```

    ```python Python
    session = hevn.post("/connect/sessions", {
        "action": "sign", "payoutId": payout["id"],
        "redirectUri": "http://localhost:8080/callback.html",
    })
    ```

    ```javascript Node
    const session = await hevn.post("/connect/sessions", {
      action: "sign", payoutId: payout.id,
      redirectUri: "http://localhost:8080/callback.html",
    });
    ```

    ```go Go
    session, err := api.Post("/connect/sessions", hevn.Body{
    	"action": "sign", "payoutId": payout.Str("id"),
    	"redirectUri": "http://localhost:8080/callback.html",
    })
    ```

    </CodeGroup>

    Sign in with the second Google account and [approve the payout](/whitelabel/sign-in-with-hevn#approve-a-payout). The page shows:

    ```json
    { "status": "submitted", "payout": "po_6d21…", … }
    ```
  </Step>

  <Step title="Read the payout">
    Do not act on the redirect. Poll `GET /dapi/v1/payouts/{payoutId}` until the status leaves `awaitingSignature` and `submitted`, then read `GET /dapi/v1/transactions`.

    <CodeGroup>

    ```bash cURL
    curl -s "$HEVN_API/payouts/$HEVN_PAYOUT_ID" \
      -H "Authorization: Bearer $HEVN_ACCESS_TOKEN" -H "X-Hevn-Account: $HEVN_CLIENT_ID" \
      | jq '{status, transactionHash}'
    ```

    ```python Python
    done = poll_until(lambda: client.get(f"/payouts/{payout['id']}"),
                      lambda seen: seen["status"] not in ("awaitingSignature", "submitted"))
    rows = client.get("/transactions", {"limit": 5})["items"]
    ```

    ```javascript Node
    const done = await pollUntil(() => client.get(`/payouts/${payout.id}`),
      (seen) => !["awaitingSignature", "submitted"].includes(seen.status));
    const { items: rows } = await client.get("/transactions", { limit: 5 });
    ```

    ```go Go
    done, err := hevn.PollUntil(
    	func() (hevn.Payload, error) { return client.Get("/payouts/" + payout.Str("id")) },
    	func(seen hevn.Payload) bool { s := seen.Str("status"); return s != "awaitingSignature" && s != "submitted" },
    	2*time.Minute,
    )
    page, err := client.Get("/transactions", hevn.Query{"limit": "5"})
    ```

    </CodeGroup>

    ```json Response
    { "status": "settled", "transactionHash": "0x3a77…" }
    ```

    In the ledger row, `from` and `to` are both `1.000000 USDC`. To see the 1 USDC in your account, repeat step 7 with `$HEVN_USER_ID` in `X-Hevn-Account`.
  </Step>
</Steps>

A transfer to `baseSmartWallet` and a payout to a wallet contact need a `ready` client and no KYB. Account details and bank payouts need an approved [KYB application](/whitelabel/clients#write-the-document) and an active [virtual account](/whitelabel/virtual-accounts).
