The REST API tab is generated from the OpenAPI document of the HEVN Platform API. Log in with `POST /dapi/v1/auth/challenge` and `POST /dapi/v1/auth/token` ([Sessions](/developers/authentication#sessions)).

## OpenAPI document

| Resource | URL |
| --- | --- |
| OpenAPI document | `https://sandbox-api.hevn.finance/dapi/v1/openapi.json` |
| Swagger UI | `https://sandbox-api.hevn.finance/dapi/v1/docs` |

Where this tab and the served document differ, use the served document.

## Servers

| Environment | Server | Notes |
| --- | --- | --- |
| Production | `https://api.hevn.finance/dapi/v1` | Live funds on Base. |
| Sandbox | `https://sandbox-api.hevn.finance/dapi/v1` | Test funds on Base Sepolia, with one emulated partner bank. |

The served document declares one relative server, `/dapi/v1`, so the host you call sets the environment. Paths are relative to that base: `/banks` is `https://api.hevn.finance/dapi/v1/banks`. `Location` headers and `pollUrl` values are absolute paths that begin with `/dapi/v1`.

The environments have separate accounts, and a token issued by one host is refused by the other. Operations tagged `sandbox` return `404` in production.

## Headers

| Header | Sent on | Defined in |
| --- | --- | --- |
| `Authorization: Bearer <accessToken>` | All operations outside the `auth` tag. `POST /auth/refresh` takes the refresh token as the bearer. | [Tokens](/developers/authentication#tokens) |
| `X-Hevn-Account: cl_…` | Operations that act for a client | [Acting as a client](/developers/authentication#acting-as-a-client) |

`/dapi/v1` does not accept `X-Api-Key`. That header authenticates [Remote Transfers](/general/remote-transfers).

## Errors

An error response is a JSON envelope with `error.code`, `error.message` and `error.details`. The OpenAPI document lists the codes in one enum, `PlatformErrorCode`, with no per-operation list. [Errors](/developers/reference/errors) gives the HTTP status and next step for each code.
